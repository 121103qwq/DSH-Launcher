# 行为 × 验证方式矩阵

> 目的：一眼看清"哪些行为有自动化保护、哪些只能人工验收、哪些没覆盖"。
> 图例：**ST** = SelfTest（`tests/DshLauncher.SelfTest`，133 条）；**HV** = harness（`_verify-p0`，含 `--ui`，348 条）；
> **人工** = 需真人点击/观察（系统文件对话框、渲染宿主、模态确认等自动化不友好的路径）；**⛔** = 无覆盖（已知缺口）。
> 维护规则：新增/修改行为时，先在这里登记"打算怎么验证"，再实现（work-log/27 #23）。
